# AD-up
Une application Android qui permet de visualiser efficacement et simplement les emplois du temps du système ADE

## Problèmes connus et perspectives d'évolution
- [ ] **BUG** : Affichage des noms non fonctionnel
- [ ] **FEAT** : Pouvoir changer de jour en faisant glisser droite/gauche
- [ ] **FEAT** : Pouvoir changer de classe sans se déconnecter

## Utilisation de l'IA
L'IA a été utilisée uniquement pour générer des Regex en dart (flemme de comprendre ce langage du démon)

## Crédits tiers
La partie du code qui gère la connexion au système ADE via les cookies s'inspire et reprend les concepts du repo [Fouinard/CPPocket](https://github.com/Fouinard/CPPocket)
